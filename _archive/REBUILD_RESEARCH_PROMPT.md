# CalChem 底层重构：高性能量子化学软件架构调研

## 角色设定

你是一名同时精通以下领域的资深架构师：
- 量子化学理论（HF/DFT/MP2/CCSD(T)、密度泛函、电子相关）
- 高性能计算（HPC、GPU、SIMD、稀疏线性代数、张量运算）
- 现代系统编程语言（Rust / C++20 / Julia / Mojo）
- 软件架构设计（模块化、零成本抽象、类型安全、可扩展性）

## 背景

我正在开发 CalChem，但当前版本（v0.6.0）是纯 Python 实现，存在致命性能问题：

1. **没有解析梯度**：几何优化和频率依赖有限差分，慢且噪声大
2. **基组极少**：只有 STO-3G 到 6-31G(d)
3. **Python 性能慢**：同样 H2O/STO-3G，PySCF（C 内核）快 10-100 倍
4. **没有溶剂模型**：PCM/SMD 未实现
5. **没有 TDDFT**：激发态无法计算
6. **没有并行**：多核用不上
7. **cube 生成是 stub**

在当前 Python 架构上修补这些问题等于在沙地上盖楼。我需要从底层重新设计，目标是开发一款在**计算速度、架构设计、方法精度**三个层面都超越 Gaussian 16 / ORCA 6 / PySCF / REST 的新一代量子化学软件。

### 3. 性能创新方向

调研以下前沿技术，评估哪些能带来真正的数量级加速：

- **自动微分**：用 AD 框架替代手写解析梯度
- **稀疏矩阵**：积分筛选、阈值丢弃
- **线性标度算法**：O(N) SCF、分治方法
- **ML 加速**：神经网络预测密度/能量/波函数
- **混合精度**：FP64/FP32/BF16 在不同迭代阶段
- **多核并行**：线程级、进程级、分布式
- **SIMD 向量化**：AVX2/AVX-512/Neon
