# CalChem v0.2.0 → v1.0 执行入口

先读 `V020_TO_V100_PLAN.md`，再读现有 handoff 文档和完整本地仓库。此包包含本次收到的 v0.1.0 handoff 内容及新增计划；本次 handoff 只有平台层部分源码，缺少原生计算内核和验收脚本，不能当作完整可构建源码仓库。

## 给本地 Agent 的执行约定

1. 按计划连续推进，阶段门通过后直接进入下一阶段。不要就常规设计选择、文件名、实现先后顺序询问用户。
2. 首先定位本地完整仓库，记录 commit、依赖和基线；把本次 handoff 与本地真实代码核对。不得以本压缩包的缺失文件推断本地仓库也不存在。
3. 每阶段完成实现、测试、文档、真实验收，再继续；失败先修复。不可把 stub、fixture、日志文本匹配或未运行的外部程序写成 PASS。
4. 同时只运行一个 heavy 量化作业，跨 GUI、CLI 和 Python API 一致。CI 的外部软件任务也串行。
5. 每个 release gate 提供可复现证据。只有外部凭据/许可、不可逆操作、用户未授权的数据外发或外部发布等确实需要用户决定时才停下相应动作；其余工作继续。
6. 最终交付时给用户安装包、完整验收矩阵、版本与构建环境、已知限制。所有不能完成的项目写明 BLOCKED 及可复现原因。

本计划是架构和执行说明，不表示 v0.2.0 至 v1.0 的功能已经实现。
