# 原生 SCF 性能解决方案
按输入对照、精确交换复用、稀疏 RI-J、度量分解、收敛检查、两体系端到端计时依次验收。72 原子原记录 301.42 秒，其中 289.97 秒包括全部双电子与最终自洽步骤。199 原子旧运行遭中断，先测实际阶段、缓存大小、线程与工作集。Gaussian 工时单独核对输入方法、线程与收敛精度。
1. 在相同几何基组下复用原始精确 ERI。按 Schwarz 上界排序，用全局密度上界早停，保留逐 quartet 的密度筛选。以固定内存预算保存已计算的普通库仑四中心块，缓存缺失走原积分路径。不同 omega 单独处理。该路线适合本轮小基组重复构建。RI-K 要验证辅助基拟合误差，COSX 要验证交换网格与力，GPU ERI 批处理适合作为热点仍在积分生成时的后续扩展。
2. 对稠密缓存超预算的 RI-J 生成显著壳对内的独立 AO 对，逐辅助行连续存储。同对角密度取一次，非对角取两个方向之和。GPU 复用原双精度收缩接口，回填对称矩阵。用现有 Schwarz 阈值界定可丢弃的块；超预算时继续逐块求积。
3. 对标准化度量先用行和上界与平移 Cholesky 验证全部特征值高于截断，再分解原矩阵。近相关情况保留谱截断。
4. 对收敛后的物理 Fock 检查规范化密度差与重建交换子，只在满足现有精度时提前结束。验证梯度及稀疏/稠密/直接积分一致性。
5. 用 release CLI 跑给定两个真实输入，记录能量、终止、分阶段耗时、GPU 遥测、峰值工作集与输入哈希。与同设置旧输出核对。任何未达到的性能目标按实测记录。
重要源码与原 CLI 在 E 盘备份，可按清单还原到单独的候选目录。所有实验用工程 dev_env。
