# CalChem P1 已知技术边界与局限性声明

**文档状态**：P1 阶段正式交付物  
**编制日期**：2026-11-10  
**基准定位**：用于客观评估 CalChem 现阶段（P1）能力的物理边界，防止过度承诺与预期偏差。

---

## 一、 体系规模与基函数覆盖边界

1. **当前严格验证上限为 72 AO**：
   * 在 P1 阶段，严格进行了数值收敛、精度对标和内存有界性测试的分子最大体系为 Ne8（6-31G 基组，**72 个基函数**）；
   * 对于极化基组，完成了水分子在 6-31G(d) 下包含 d 壳层轨道的无筛选对标（**19 个基函数**）；
   * 虽然 Direct SCF 架构在算法上消除了双电子积分显式存储的内存屏障（不再受限于 4 GiB 存储瓶颈），但目前**尚未在 100~500 AO 以及千级基函数上完成系统的性能标定**。

2. **超大体系（Y6: 2374 AO，p4D18: 6224 AO）的现实计算壁垒**：
   * **内存可行性**：在单张矩阵 $300\text{ MB}$、固定 16 线程缓冲池及全状态准入模型下，p4D18 的常驻内存在 **5~8 GB 之间**，在 16 GB 物理内存的工作站上不会触发 OOM 崩溃；
   * **时间复杂度壁垒**：Gaussian 16 在 40 核心高性能计算节点上计算 p4D18 单步优化历时 **近 7 天（276 天 CPU 累计时间）**。CalChem 现阶段采用的是纯 CPU 动态收缩与 Schwarz 剪枝，尚未引入 **RI-J（密度拟合）** 与 **FMM（快速多极展开）**。在没有 RI-J 的情况下，万亿级四中心积分对单一 CPU 的计算耗时极其漫长，不具备日常科研实用性。

---

## 二、 关键算法依赖项的阶段性限制

| 算法特性 | P1 当前状态 | 局限性说明 | 规划解决阶段 |
| :--- | :--- | :--- | :--- |
| **四中心 ERI 评估** | CPU 纯解析动态计算 (Obara-Saika / McMurchie-Davidson) | 计算时间随基函数数迅速攀升，缺乏辅助基拟合 | P2: RI-J / 密度拟合 |
| **GPU 加速** | 未接入（纯 CPU 多线程） | 无法利用本地 RTX 5060 Ti 的张量核心算力 | P3: CUDA 混合内核 |
| **范围分离泛函** | 被安全守卫拦截并拒绝执行 (`legacy_lrc_enum_is_not_a_backdoor`) | 无法直接计算 CAM-B3LYP 与 $\omega\text{B97X-D}$ 的长程交换积分 | P2: erf/erfc ERI 递推 |
| **积分剪枝策略** | 仅 Cauchy-Schwarz $L_1$ 块范数剪枝 | 远距离壳层衰减仅依赖积分绝对值，缺乏多极远场近似 | P3: FMM 快速多极展开 |
| **内存预算上限** | 默认硬上限 8.0 GiB | 防止 16 GB 宿主机发生物理内存耗尽；超大体系需配置更大 RAM | P2: 外存交换与低秩张量 |

## 三、 对科研生产环境的使用建议

1. **推荐适用场景**：
   * 原子数 $\leq 50$，基函数数 $\leq 300$ 的中小有机分子、配合物的纯密度泛函（LDA、GGA 如 PBE）与杂化泛函（B3LYP）；
   * 需严格保证单机计算内存不超过 8 GB 的并发工作流任务；
   * 基态电子结构单点能、Mulliken/Löwdin 布居分析与偶极矩计算。

2. **暂不建议场景**：
   * 未经 RI 加速的 $> 1000$ 基函数超大共轭体系（如 p4D18、完整光伏受体二聚体）的大规模全解析 SCF；
   * 依赖范围分离泛函（$\omega\text{B97X-D}$、CAM-B3LYP）的高精度电荷转移激发态计算（需等待 P2 阶段范围分离积分上线）。
