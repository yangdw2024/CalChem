# 同条件性能分析计划

先核对上一轮 Gaussian 输出及 REST 源码，确认计算定义、线程、收敛和时间。运行 CalChem 的 4 线程 B3LYP/PTQ10 与 PBE/BTP-4F，设置能量 1e-6 Eh、密度 1e-8，与 Gaussian 输出显示的阈值一致。逐例记录输入、二进制哈希、完整命令、峰值工作集、总墙钟时间、分段时间、SCF 步数、能量与 GPU 遥测。两次运行串行完成。

Gaussian Coarse 网格与 CalChem Coarse 网格、自动 RI-J 与 Gaussian 库仑路径不保证相同。结果用于评估对齐线程和部分收敛门槛后的速度，不将其标记为严格同算法比较。核对 REST 已有的源码和真实运行记录，单列观察、推断和未验证部分。根据热点制定具体优化顺序并说明可复现验收条件。
