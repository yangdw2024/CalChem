# CalChem 第二轮验收与修复 — 2026-11-10

## 授权与规则
用户授权重新审计并直接修复发现的缺陷。以磁盘最新源码和新运行数据为准；上一轮仅作反例与参考输入来源。不得把单点符合、测试全绿、近似模型或拒绝不支持功能说成完整科学实现。

全部新增文件、运行缓存、编译产物在 E 盘，工具链在 D 盘；C 盘只读。不安装依赖，不清理用户文件，不 reset/clean，不提交或发布。修改前保留完整源码、未跟踪文件和当前扩展的 SHA256 快照；恢复只解压至独立候选目录，绝不覆盖原工作区。

## 当前状态与工作流
工作区仍有大量用户未提交修改；当前 Git HEAD 不是运行版本的充分描述。13 Rust crates 经 calchem-py/PyO3 暴露给 Python，Python native backend/workflows 可走其他回退路径。开发团队于 11 月 9 日晚修改 Boys、IR、TS、IRC、D3、SCRF、网格与 setup.py。先记录这些修改的实际行为，再做本轮补丁。所有改动另存 unified diff 与完整替换文件，避免和历史用户修改混淆。

## 执行计划
1. 保存源码/扩展基线与 Git 状态，重跑 workspace tests；比对源码构建和磁盘扩展。
2. 独立复测八项：高精度 Boys、Gaussian IR、极小值/鞍点认证、IRC 终点、标准 D3、独立气相/溶剂导数、弥散密度积分、干净源 wheel。
3. 排查开壳层/ECP/近简并/输入异常/LRC 声明/GIL/张量容量。压力测试采用有界规模，禁止主动耗尽宿主内存或杀死用户进程。
4. 对确认缺陷先保留失败证据，然后修复；无法完整实现的科学方法必须明确拒绝，不能换公式或名称掩盖。
5. 增加独立回归、重编译并验证扩展/包装层；更新结论、验收表、完整修复代码、证据和使用边界。

## 验收原则
SCF/DIIS 能量不必逐步单调；收敛和自洽残差才是验收条件。UHF/UKS 的自旋污染是可诊断性质，不能将其误当作已实现自旋投影。有限差分一致性不能替代外部物理模型认证。平台只能声明实际验证过的范围。
