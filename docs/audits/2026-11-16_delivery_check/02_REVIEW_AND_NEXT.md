## 仍需修正的具体结论

- PBE 常数归因写得过满。Lehtola/Marques 的原始研究明确给出 Gaussian PBE 交换等效参数 kappa=0.804000423825475、mu=0.219510240580611；不能直接用 mu=0.21951 代替，也不能仅由余差大小判定全部来源。本轮看到的生成脚本只写入了常数归因注释，没有固定密度参数替换的 A/B 证据。CalChem 还需核对 PW92 相关参数版本；并无证据表明换三个四舍五入常数就能复现 Gaussian。
- 使用两个密网格得到接近结果，支持当前算例的一致性；严格的网格收敛仍应留至少两个递增网格的数值，不把“更密”直接等同“已到极限”。
- CPU/GPU 端到端容差 5e-6 Eh/1e-3 eV 在当前较松 SCF 停止阈值下可以用于工作流回归，但它不等于同一输入密度下 GPU 缩并核的精度。FMA/条件数解释需要固定 B 张量与 x 向量的直接缩并对照，及重复运行噪声测量；cond(V) 与 max|V^-1| 是不同量，不能互相代替。
- RI-J 测试实际断言为 1.5e-4 Eh，宽于原目标 1e-4 Eh；虽然本次四个值均达标，6-31G 仅剩约 6.7e-7 Eh 裕量，应明确这一点。
- 满秩逆残差改善是真进展，但仍用显式 V^-1 收缩；后续可比较保留 Cholesky 因子后解方程的数值稳定性。核梯度绑定对 RI-J 固定使用 1e-7/1e-7，应该有调用方选择精度的入口，并验证目标精度能否达到。
- 当前制品清单没有覆盖全部源码和回归日志的 SHA256；git HEAD 无法表示大量未提交源码。补一次快照哈希即可，不必为补清单重新跑全套。
- 大量成功数值依然集中在 H2/H2O，四个基组不等于四个化学环境。N/F/S 有机体系的精确库仑参考、实际几何优化、较大体系 RSS/VRAM 仍是下一阶段价值所在。

## 接下来直接执行的任务（按顺序）

1. **RI-J 稳定性和 GPU 精度短闭环。** 固定同一密度，比较 CPU/GPU 同一 B 和 x 的缩并；同时比较显式逆与 Cholesky 求解。记录条件数定义、J 最大误差、能量误差和重复噪声。若求解改善噪声与 SCF 稳定性，保留因子并修复实际调用；依据定向结果设算子容差。验收：不依靠放宽 SCF 阈值来证明算子准确。
2. **PBE 差异归因。** 使用已知固定密度，分别验证标准 PBE 与 Gaussian PBE 的交换参数、PW92 相关参数；把交换/相关误差拆开，再跑 H2O 的 PBE/PBE0 两个 SCF 对照。保留参数、参考来源和原始结果。验收：A/B 数值确实解释原余差，再改归因报告；不要为匹配单个分子能量拟合参数。
3. **推进真实有机化学验证。** 挑选至少包含 N/F/S 的三个小分子，固定几何，测试 6-31G(d) 下 exact J 与 RI-J 的能量和梯度；再给 IC-2F 增加一次精确库仑基线。报告逐分子误差、n_aux/n_ao、时间和内存。目标误差 1e-4 Eh 是这些基准的验收值，不能直接当成任意大分子的统一保证。
4. **走实际规模与用途。** 选择现有结构中的约 50–100 原子体系，先单点能与全进程峰值 RSS/VRAM；小体系先验证短几何优化。完成后再决定是否扩大到 Y6。优化前先记录 RI-J 初始化、精确交换 K、DFT 网格与 GPU 传输各部分耗时，按最大耗时项优化。

执行方式：每次改动先备份受影响重要文件；先跑对应定向算例，失败就修同一个问题；物理核心变更稳定后统一跑一次全量回归。每一步交付“实际修改、原始数据、通过或失败、下一步”，不再重复写宏观审计提纲。
