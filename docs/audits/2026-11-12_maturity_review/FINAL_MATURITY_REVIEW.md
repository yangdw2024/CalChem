## 仍阻断生产级结论的具体问题

1. **全进程内存未锁定。** Vxc 流式路径仍按工作分块保留稠密 AO² 势矩阵；SCF 对角化、Fock、密度、梯度和 DIIS 还要共享内存。6224 AO 的单张 f64 矩阵约 295.55 MiB。没有当前版本 726 原子全 SCF 的收敛输出与进程 RSS/显存时间序列；不能宣称“16 GB 保证”。
2. **DIIS 磁盘故障可能静默回 RAM。** `diis.rs:197-214` 吞掉临时文件创建/读写/锁定失败，然后复制完整历史到内存。这违背其内存上限目标。`std::env::temp_dir()` 在直接使用 API 时还可能写到 C 盘；审计脚本把 TEMP/TMP 指向 E 盘，不代表所有应用启动方式都如此。
3. **RI-J 截断度量梯度未闭环。** `invert_coulomb_metric` 截断近零特征模，`compute_coulomb_gradient` 没有区分截断情况。普通逆的驻值导数不能无条件用于随几何变化的截断广义逆。需拒绝该边界或实现投影子空间导数及独立有限差分验证。
4. **GPU 端到端价值未证实。** 成功的 128×32² 算子对照证明执行与双精度；未证明大体系里三中心积分生成/传输/缩并的总加速。Driver API 初始化失败路径尚有重复 `LoadLibraryA`/主上下文 retain 清理风险。
5. **方法与外部精度覆盖不足。** wB97X-D、SMD、RI-J TDDFT、开放壳层响应、范围分离 SCRF 仍不可用；应持续明确拒绝。当前 OPV 检查中的结构/日志读取不能算作大分子计算。
6. **可复现发布状态不足。** 当前数值运行版本包含大量未提交文件；需要冻结源码哈希、二进制、测试环境和同方法外部基准，才能给可复现实验或发布版本下更强结论。

## 评级与使用建议

- **研究开发价值：B。** 核心路径真实、结构较完整，当前版本 137 Rust + 119 Python 回归全绿，GPU 算子也已实测。
- **科学方法可靠性：C。** 可以在已验证方法/基组/体系范围内开展探索，正式论文结果需与 Gaussian/ORCA 等独立实现按完全相同设置交叉验证。
- **大体系与工业生产准入：D。** 726–2000 原子资源/收敛/精度尚无实测证明，多个标准模型还缺失。

以上评级是本次审计判断，不是行业标准等级。最贴切的产品阶段是 **Alpha 后期的研究软件**：具备可用核心和自动回归，距离可托付大规模 OPV 生产计算仍有明确工程与物理验收工作。
