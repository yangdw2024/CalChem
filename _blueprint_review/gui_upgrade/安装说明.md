# CalChem GUI 升级说明

## 升级内容

本次升级为 CalChem GUI 添加了以下功能：

### 1. 分子片段库
- 在主窗口添加了"插入片段"菜单
- 片段包括：水(H2O)、甲烷(CH4)、苯(C6H6)、乙烯(C2H4)、乙炔(C2H2)、氨(NH3)、二氧化碳(CO2)
- 点击插入后自动添加到当前分子的末尾
- 片段坐标使用标准几何

### 2. 分子轨道可视化
- 在结果展示区添加了"轨道能级图"标签页
- 显示轨道能级图（能级 vs 轨道序号）
- 点击轨道可以显示轨道详细信息
- 标注HOMO/LUMO位置
- 显示HOMO-LUMO能隙

### 3. 振动模式动画
- 如果结果中有频率数据，显示频率列表
- 点击频率可以播放简正模式振动动画
- 使用QTimer逐帧更新原子位置
- 支持播放/暂停/停止控制
- 可调节振动幅度

### 4. 性能显示
- 在状态栏显示计算耗时
- 显示内存使用（每3秒更新）

## 功能使用说明

### 1. 使用分子片段库

1. 打开 CalChem 主窗口
2. 点击菜单：**编辑 → 插入片段**
3. 选择要插入的片段（如"水 (H2O)"）
4. 片段会自动添加到当前分子末尾，自动偏移避免重叠

### 2. 查看分子轨道能级图

1. 运行单点能计算或几何优化
2. 在右侧结果展示区切换到"轨道能级图"标签页
3. 查看：
   - 蓝色线条：占据轨道
   - 红色线条：空轨道
   - HOMO/LUMO 位置已标注
4. 点击轨道线条可查看详细信息

### 3. 播放振动动画

1. 运行频率计算（Freq）
2. 在"频率/振动"标签页查看频率列表
3. 点击表格中的某一频率行
4. 点击"播放"按钮开始动画
5. 使用滑块调整振动幅度
6. 点击"停止"按钮停止动画

### 4. 查看计算性能

- 计算进行时：状态栏显示实时耗时
- 计算完成后：状态栏显示最终耗时
- 内存使用：状态栏右侧显示（每3秒更新）

## 代码变更详情

### main_window.py 主要变更

1. **添加分子片段库数据结构**：
   ```python
   _FRAGMENTS = {
       "水 (H2O)": {...},
       "甲烷 (CH4)": {...},
       ...
   }
   ```

2. **添加"插入片段"菜单**：
   - 在编辑菜单中添加子菜单
   - 包含7种常见分子片段

3. **实现 `_insert_fragment()` 方法**：
   - 获取片段坐标
   - 计算偏移量避免重叠
   - 合并到当前分子

4. **添加计算耗时记录**：
   - `_calc_start_time`: 记录开始时间
   - `_calc_elapsed_time`: 记录总耗时
   - `_update_time_display()`: 更新状态栏显示

5. **修改状态栏**：
   - 添加耗时标签 `lbl_time`

### result_viewer.py 主要变更

1. **新增 `OrbitalLevelPlot` 类**：
   - 使用 matplotlib 绘制轨道能级图
   - 支持点击交互
   - 显示 HOMO/LUMO 标注

2. **新增 `VibrationAnimator` 类**：
   - 使用 QTimer 实现动画
   - 简谐振动模型
   - 支持播放控制和幅度调节

3. **修改 `ResultViewer` 类**：
   - 添加"轨道能级图"标签页
   - 增强"频率/振动"标签页（添加动画控制）
   - 添加计算耗时显示
   - 修改 `display_results()` 接受 `calc_time` 参数

## 注意事项

1. **matplotlib 依赖**：
   - 轨道能级图需要 matplotlib
   - 如果未安装，会显示提示信息，不影响其他功能

2. **振动动画**：
   - 需要计算结果中包含 `mode_vectors`（振动模式向量）
   - 如果没有模式向量，动画功能仍可使用但不会更新原子位置

3. **向后兼容**：
   - 所有新功能都不影响原有功能
   - 如果不想使用新功能，可以恢复备份文件

4. **性能影响**：
   - 轨道能级图在大量轨道时可能稍慢（建议 < 200 轨道）
   - 内存显示每 3 秒更新，对性能影响极小

## 故障排除

### 问题1：轨道能级图不显示

**解决方案**：
```bash
pip install matplotlib
```

### 问题2：振动动画不更新原子位置

**原因**：计算结果中缺少 `mode_vectors` 数据

**解决方案**：确保频率计算输出了振动模式向量

### 问题3：片段插入位置不合理

**解决方案**：
- 可以使用"居中分子"功能调整位置
- 或手动编辑原子坐标
