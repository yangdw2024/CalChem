# CalChem Complete Product Blueprint Package

This archive contains the original CalChem source/handoff bundle plus an execution-ready product blueprint.

Start with `blueprint/00_READ_ME_FIRST.md`, then read the remaining files in `blueprint/`. The original project is at the archive root (`calchem/`, `tests/`, `handoff/`, and project files).

The blueprint specifies product scope, Python/PyQt6 stack, architecture, API/data contracts, desktop UI, backend integration, Windows packaging, phased tasks, and final acceptance gates. The local agent should complete all phases and acceptance before reporting back; it must not claim external backends passed without running the actual programs.
